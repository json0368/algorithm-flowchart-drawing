# 排版、原生文件与导出检查

## 适配报告页面

先取得报告的纸张、页边距与插图宽度；没有资料时可用 A4、图宽约 15 cm、高不超过约 24 cm 作为试排起点。这是排版起点，不是所有报告的强制标准。

若用户没有指定字号，使用 draw.io 的 `fontSize=15`，同时检查最终物理大小。若编辑器字体为 15，图宽 W 个绘图单位，最终图宽为 w 磅，则文字约为 `15 × w / W` 磅。例如 700 单位宽的图放到 15 cm（约 425 磅）宽，文字仅约 9.1 磅。因此不能靠源文件标着 15 就声称最终 PDF 可读。

优先用矢量 PDF/SVG，PNG 一般按最终尺寸导出至少 300 dpi；提高像素只会改善清晰度，不能补救字的物理尺寸过小。检查时使用报告的目标纸张和实际插图尺寸，不能只看占满屏幕的单图预览。

## 紧凑但不拥挤

- 把循环主干放在一列，把分支或内层处理放在侧列，减少纸张上无效的高度。
- 按节点文字实际调整尺寸；菱形左右可用文字空间小于外接矩形，不要把文字塞满菱形宽度。
- 判断与相邻连接点之间留足“是/否”标签及箭头空间。长循环使用配对连接点时，回接目标放在恰当的条件或更新之前。
- 同页连接点可采用：一个接收流程的 A 圆点（有入边），另一个继续流程的 A 圆点（有出边）。多个分支可回到同一个明确的继续位置。若需要跨页续接，采用参考规范要求的跨页符号并标明图号，不能让同字母在多页间含混对应。
- 连接点只是替代长线，不替代运算。逐条检查它有没有绕过 `i 加一`、有效长度调整、出栈等必要步骤。
- 入边、循环回边、退出边分开走。若线段重叠或视觉上像汇合，移动节点并显式设置转折点。

一个可调整的两列布局例子：主列中心约 180，侧列中心约 570，主菱形宽 280，侧菱形左缘约 430。两列之间安排直径约 28–32 的连接点时，需另外保留分支标签和箭头间隔。不要将这些坐标机械套用到不同文字和页面。

## 原生 draw.io 文件

使用 XML 库生成 `<mxfile><diagram><mxGraphModel><root>…`，让库负责特殊字符转义。每页保留根单元 `0` 和 `1`，其他 ID 使用 `cell_`、`edge_` 等前缀，页内唯一，并保持 source、target、parent 引用正确。

若桌面导出报 `TypeError: d.setId is not a function`，可检查是否使用了 `map` 等可能与内部属性冲突的裸 ID，并尝试统一添加前缀、同步更新引用。也应检查原生文件结构，不要仅凭该错误判断为导出超时。

每条边都必须具有几何信息，例如：

```xml
<mxCell id="edge_next" edge="1" parent="1"
        source="cell_check" target="cell_step"
        style="edgeStyle=orthogonalEdgeStyle;endArrow=block;">
  <mxGeometry relative="1" as="geometry"/>
</mxCell>
```

用边样式指定出入端口，复杂走线在 `mxGeometry` 中添加 `Array as="points"` 与 `mxPoint`。源文件字体、连线文字字体保持一致。中文节点可使用 Microsoft YaHei、宋体等实际存在的字体，导出后检查是否缺字。

## 渲染与核验

优先使用已安装的 draw.io 桌面 CLI 导出；也可用可用的浏览器渲染方式。不把联网预览作为唯一前提。运行 GUI 或写入受限位置时遵循当前环境的权限要求。

CLI 形式（具体选项以本地工具帮助为准）：

```text
drawio --export --format pdf --all-pages --output output.pdf input.drawio
```

必要时使用输出目录内的独立用户配置目录避免桌面实例干扰。不要固定依赖特定电脑的安装路径、日期目录或特定项目的文件。

导出后核验：

1. 检查输出文件由当前导出操作生成且可解析；多页文件页数应与预期一致。进程退出码为 0 不能单独证明导出成功，日志可能仍含 Export failed。
2. 将最终 PDF 渲染为图片逐页查看，检查中文、文字裁切、图形重叠、边标签与箭头位置。总览适合检查一致性，不能替代逐页阅读。
3. 对照代码走一遍成功路径、各关键分支、循环继续/终止及实际存在的错误路径。特别检查字符增删后的下标和递归退出时的集合维护。
4. 在实际报告尺寸下复查；不要用任意缩放的截图作为“100% 可读”的证据。若只能做渲染近似检查，注明检查方法，不宣称已经在用户的 PDF 阅读器里确认。

静态检查至少包括：XML 可解析、页内 ID 唯一、source/target/parent 有效、边有相对几何信息。可额外检查图形重叠、字体和连接点配对，但不能据此认定没有连线交叉或文字溢出。

## 交付整理

默认保留主 `.drawio`；多页图可附独立页面文件。根据用户需求交付 PDF、PNG 或 SVG，不强制生成所有格式。若图供报告插入，附一份简短对应表：图名、算法/函数、报告小节、建议放置位置。临时预览和导出工具配置放在工作目录，不混入成品包。
