# Algorithm Flowchart Drawing

根据实际源代码绘制详细、可编辑的 draw.io 算法流程图，适用于课程设计、实验报告和毕业设计。支持对照报告描述组织总体图与详情图。

## 使用方式

在 Codex 中选择“Algorithm Flowchart Drawing”，或直接输入：

```text
使用 $openai.yaml，为这个函数绘制算法流程图。
```

提供待绘制的源代码；如有报告正文、绘图规范或参考图片，也可以一并提供。可以指定字号、纸张尺寸、详略程度和导出格式。

## 默认规格

若用户没有要求，则采用以下规格：

- 使用简短中文描述，展开关键循环、条件分支、数据操作及下标更新。
- 使用黑白基础图形，draw.io 字号为 15。
- 按完整算法阶段划分子图，采用分栏、折线和连接点组织布局，尽量避免连线交叉。
- 按最终插图尺寸检查 PDF 100% 显示时的可读性。
- 保留可编辑的 `.drawio` 文件，按需导出 PDF、SVG 或 PNG。

用户明确提出的要求优先于默认规格。
